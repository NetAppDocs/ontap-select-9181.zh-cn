= 调整 ONTAP Select 集群节点的大小
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
部署 ONTAP Select 群集后，可以使用 Deploy 管理实用程序升级节点的虚拟机监控程序实例类型。


NOTE: 使用 Capacity Tiers 许可模型和 Capacity Pools 许可模型时，可以执行集群节点大小调整操作。


NOTE: 只有 ESXi 才支持调整为大型实例类型。

.开始之前
集群必须处于在线状态。

.关于此任务
此任务介绍如何使用 Deploy Web 用户界面。您还可以使用 Deploy CLI 执行实例大小调整。无论您使用哪种接口，调整大小操作所需的时间可能会因几个因素而有很大差异，并且可能需要较长时间才能完成。您只能将节点的大小调整为更大的大小。

.步骤
. 使用管理员帐户 Sign in 到 Deploy 实用程序 Web 用户界面。
. 单击页面顶部的 *Cluster* 选项卡，然后从列表中选择所需的集群。
. 在集群详细信息页面上，单击页面右侧的齿轮图标并选择 *Instance Resize*。
. 选择 *Instance Type* 并提供 ONTAP 凭据，然后单击 *Modify*。


.完成后
您必须等待调整大小操作完成。

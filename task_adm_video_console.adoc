= 访问 ONTAP Select 视频控制台
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以访问运行 ONTAP Select 的虚拟机管理程序虚拟机的视频控制台。

.关于此任务
您可能需要访问虚拟机控制台以解决问题或在 NetApp 支持人员要求时执行此操作。

.步骤
. 访问 vSphere 客户端并登录。
. 导航到层次结构中的适当位置以查找 ONTAP Select 虚拟机。
. 右键单击虚拟机并选择 *Open Console*。

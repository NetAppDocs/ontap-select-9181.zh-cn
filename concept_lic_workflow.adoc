= 购买 ONTAP Select 许可证时的工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
以下工作流程说明了为 ONTAP Select 部署购买和应用许可证的过程。购买许可证时，必须选择许可模式和存储容量。

具体流程取决于您使用的是 Capacity Tier 还是 Capacity Pool 许可证：

九位数许可证序列号:: 序列号适用于节点（Capacity Tiers）或存储池（Capacity Pools）
许可证锁定 ID:: 使用容量池许可证时，您必须具有 Deploy 实例的许可证锁定 ID
许可网站:: 您可以在不同的网站上获得 Capacity Tier 和 Capacity Pool 许可证
